### 🛠️ Run Locally

### 🌍 GitHub Pages

1. Upload these files to a GitHub repository.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Choose `main` and `/root`.
5. Save.
6. GitHub will provide the public website URL.
